# 矩形凹槽 8 灯珠动态灯效（已实现，待实车校对）

两条 8 灯珠灯带按逻辑位置 `0..7` 设计；逻辑 `0` 为车头端、`7` 为车尾端。默认左侧为 WS3/PF11/group 2，右侧为 WS4/PF12/group 3，两侧物理第 1 颗（代码索引 0）都假设在车头端。这些只是软件默认值，实际位置和 DIN 方向尚未上车确认。修改 `App/Inc/lighting/lighting_controller.h` 的 `LIGHTING_LEFT_STRIP_GROUP`、`LIGHTING_RIGHT_STRIP_GROUP` 可交换左右；将对应 `LIGHTING_*_STRIP_REVERSED` 从 `0` 改成 `1` 可反转该侧灯珠顺序，无需反接灯带。

AUX8 第 7 档（归一化 `+0.50` 至 `+0.75`，建议设在 `+0.625`，约 RC 1813 μs）已由“红蓝警灯演示”替换为“车辆联动”；其余档位保持原样，OFF 不会被联动覆盖。AUX9 在联动档控制整体亮度 `0..200/255`；运动方向、填充长度和流速来自油门和转向。

| 状态 | 8 灯珠画面 | 可辨识信息 |
| --- | --- | --- |
| 油门中位，未刹车 | 暗红底光，中心两珠向两端缓慢扩散再收回；亮度不归零 | 驻车/待机，不与刹车高亮混淆 |
| 正向油门 | 橙红能量条从车头向车尾填充，长度随油门分级变化；暖色高亮光点随油门加速移动 | 填充长度与流速表达油门大小 |
| 倒车 | 低亮红底，两个白色光点从车尾向车头移动；白色始终可见 | 白色与反向运动区别于前进 |
| 刹车 | 全条红色冲击波由两端向中心收束两次，再保持明显的红底；不出现全黑间隙 | 持续红色表示刹车，脉冲增加动感 |
| 左/右转向 | 与尾灯同一 666 ms 周期的琥珀色逐珠扫动；左/右方向由物理车头/车尾映射决定 | 琥珀色与尾灯同步，尾灯负责明确左右侧 |
| 刹车+转向 | 刹车红底不消失，琥珀扫动只覆盖前景 | 两种状态同时可见 |
| 倒车+转向 | 保留白色倒车核心，琥珀扫动用其余像素 | 不把倒车误显示为纯转向 |
| 失联/故障 | 灯条关闭；两组尾灯继续原有安全提示 | 装饰灯不掩盖故障码 |

当前优先级：失联/故障 > 刹车与转向叠加 > 倒车与转向叠加 > 油门动画 > 待机。正向油门阈值 `>+0.12`，倒车 `<-0.20`；转向阈值 `±0.30`。转向动画从方向输入越过阈值的瞬间开始，方向切换或回中后重新起步，而不是锁定系统绝对时间。刹车为已有的“正向行驶后油门快速下降”推断，保持约 600 ms，并非真实刹车传感器。全部 24 灯珠仍共享当前 850 mA **估算值**限流；它不是实测电流保证。

实车仍须确认：图中灯条实际是 WS3 还是 WS4、两条灯带物理第 1 颗在车头端还是车尾端、左右是否与上述默认值一致。软件已实现并通过主机测试，但尚未烧录或验证实车视觉效果；尤其须在装车后检查左右转向是否对应、倒车白光是否由车尾向车头运动。若只有单条矩形灯带，而非左右各一条，则目前的软件左右转向分配需要重新设计。
